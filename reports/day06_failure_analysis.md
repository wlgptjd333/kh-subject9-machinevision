# Day 06 — OCR 검사 결과 및 실패 분석

## 1. 정상 제품 이미지 6장 검사

확정한 OCR 설정(`day06-ocr-v1.0`)을 제품 이미지 6장에 동일하게 적용했다.

|설정 항목|적용 값|
|---|---|
|전처리|`original` (원본 ROI 사용)|
|이미지 확대|4배|
|OCR 엔진|Tesseract (`PSM 7`: 한 줄 문자 인식)|
|Whitelist|숫자 `0~9`만 허용|
|Regex|`^[0-9]{13}$` (숫자 13자리)|

ROI 좌표는 교재에 적힌 좌표를 그대로 사용했다.

|평가 항목|결과|의미|
|---|---|---|
|OCR 정확도|6/6 (100%)|실제 인쇄된 SN을 모두 정확하게 읽음|
|제품 판정 정확도|6/6 (100%)|OK 4장, 교육용 NG 2장을 모두 정답대로 판정|

제품 판정 정확도 100%는 모든 제품이 OK라는 뜻이 아니다. OK와 NG를 모두 정답대로 맞혔다는 뜻이다.

## 2. 영상 상태 변화 테스트

같은 SN `0637145699424`에 조건을 적용하고 OCR 결과를 확인했다.

|테스트 조건|OCR 결과|인식|확인한 내용|
|---|---|---|---|
|Low Contrast|`0637145699424`|성공|글자가 옅어져도 읽음|
|Blur|빈 문자열|실패|숫자 획이 흐려져 읽지 못함|
|Tilt|`9728`|실패|13자리 중 일부만 인식|
|Tilt + Deskew|빈 문자열|실패|회전으로 되돌려도 복구되지 않음. 변형 이미지에서 왼쪽 숫자 아래쪽이 ROI 밖으로 잘려 있어 이것도 원인일 수 있음|
|Glare|빈 문자열|실패|반사가 뒤쪽 숫자를 가림|

결과: 5개 조건 중 성공 1개, 실패 4개. 여기서 실패는 OCR 인식 실패이고, 제품 SN이 잘못 인쇄됐다는 뜻이 아니다.

## 3. 결과 해석과 개선 방향

정상 이미지에서는 OCR과 제품 판정이 모두 정확했지만, 영상 품질이 바뀌면 같은 Rule이 쉽게 실패했다.

1. 촬영 환경 개선: 초점·셔터속도로 흐림을 줄이고 조명 각도로 반사를 줄인다.
2. 전처리·설정 재검토: 기울기 보정, 대비 조절, 확대율, Tesseract 설정, ROI 여유를 바꿔 본다.
3. 재평가: 개선한 설정을 정상 이미지와 실패 이미지에 모두 적용해 비교한다.
4. 필요한 경우: 다른 OCR 엔진을 비교하고 다양한 조건의 데이터를 수집한다.
