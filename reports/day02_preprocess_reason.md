# Day 02 전처리 선택 이유

기준 이미지는 강사 제공 `cap_on_reference.jpg`(1일차 17절 실시간 ROI 결과, 검은 병뚜껑, 213×198)입니다.
`dark` · `low_contrast` · `noise` · `blur`는 이 이미지에서 코드로 만들었고, 강사 제공 파일과 픽셀까지 같았습니다.

---

## 0. Color Space 비교 (`09_color_space.py`)

| 채널 | 관찰 |
|---|---|
| BGR | 병뚜껑이 짙은 남색, 배경은 밝은 회색 |
| Gray / V | 거의 같은 모습. 병뚜껑(어두움)과 배경(밝음)의 밝기 차이가 큼 |
| H | 채도가 낮은 이미지라 색상값이 불안정 — 네모난 덩어리 Noise가 많음 |
| S | 병뚜껑(약간 푸른빛) 부분이 배경보다 밝게 보임 |

판단: 이번 병뚜껑은 **색보다 밝기 차이**가 크므로 이후 실습은 **Gray**를 사용한다. H는 채도가 낮을 때 믿기 어렵다.

---

## 1. Brightness 비교 (`10_brightness_contrast.py`)

- 사용 이미지: `dark.jpg` / alpha = 1.0 고정, beta = 0, 20, 50, 80

| alpha | beta | 결과 해석 |
|---:|---:|---|
| 1.0 | 0 | 가장 어둡다. 병뚜껑 홈이 잘 보이지 않는다. |
| 1.0 | 20 | 조금 밝아져 병뚜껑 형태가 더 잘 보인다. |
| 1.0 | 50 | 병뚜껑과 주변을 비교하기 쉽다. |
| 1.0 | 80 | 홈은 가장 잘 보이지만 전체가 뿌옇고 투명 병 부분 세부가 약해진다. |

판단: beta = 20~50이 자연스럽다. beta는 **모든 픽셀에 같은 값을 더하므로** 배경도 같이 밝아진다.

## 2. Gamma 비교 (`11_gamma.py`)

- 사용 이미지: `dark.jpg` / gamma = 0.6, 0.8, 1.0, 1.2, 1.5, 2.0
- 이 코드는 `(픽셀/255) ^ (1/gamma)` 이므로 **gamma > 1이면 밝아지고, < 1이면 어두워진다.**

판단: gamma = **1.2~1.5**가 적절. 어두운 병뚜껑 홈은 밝아지면서 이미 밝은 배경은 덜 밝아져 beta 80보다 덜 뿌옇다.
gamma 2.0은 전체가 회색으로 들뜬다.

## 3. CLAHE 비교 (`12_clahe.py`)

- 사용 이미지: `low_contrast.jpg`(Gray) / clipLimit = 1.0, 2.0, 3.0, 4.0, tileGridSize = (8, 8)

판단: **clipLimit = 2.0**. 1.0은 효과가 약하고, 3.0 이상은 홈과 함께 배경 Texture·Noise도 강하게 강조된다.

## 4. Filter 비교 (`13_filter_compare.py`)

- 사용 이미지: `noise.jpg`(Gaussian Noise + 흰/검 점 Noise)

| Filter | 관찰 |
|---|---|
| Gaussian 3 | Noise가 조금 줄지만 흰 점이 남음 |
| Gaussian 7 | 깨끗하지만 경계·홈이 흐려짐 |
| **Median 3** | 점 Noise가 대부분 사라지고 경계 유지 → **가장 적절** |
| Median 7 | 가장 깨끗하지만 홈이 거의 사라짐 |
| Bilateral (9, 75, 75) | 경계는 유지되지만 흰 점 Noise가 남음 |

판단: 점(salt-pepper) Noise에는 **Median 3**. Kernel이 커질수록 작은 특징(홈·작은 결함)이 사라진다.

## 5. Sharpening (`14_sharpen.py`)

- `blur.jpg`(Gaussian 7×7) → 3×3 Kernel `[[0,-1,0],[-1,5,-1],[0,-1,0]]`
- 흐린 홈과 경계가 다시 보이지만, 원본만큼 복원되지는 않고 경계 주변이 약간 거칠어진다.

판단: 흐림이 약할 때만 보조로 사용. Noise가 있는 이미지에는 Noise도 함께 강조되므로 주의.

## 6. Threshold / Otsu (`15_threshold_otsu.py`)

- 사용 이미지: `low_contrast.jpg`(Gray), `THRESH_BINARY_INV`(어두운 병뚜껑 → 흰색 객체)

| 방법 | 결과 |
|---|---|
| 80 | 전부 검은색 — 80보다 어두운 픽셀이 거의 없음 |
| 120 | 병뚜껑이 흰색 객체로 분리 |
| 160 | 전부 흰색 — 배경까지 선택 |
| **Otsu (자동 118)** | 120 근처를 자동으로 찾아 병뚜껑 분리 |

판단: 저대비 이미지는 고정값을 조금만 잘못 정해도 완전히 실패한다. **Otsu**가 기준값을 자동으로 찾아준다.

## 7. 전처리 전·후 비교 (`16_preprocess_compare.py`)

| 조합 | Otsu 값 | 관찰 |
|---|---:|---|
| Original + Otsu | 118 | 병뚜껑 윗면은 분리, 아래 링 일부가 끊기고 작은 점이 생김 |
| **Gaussian(5) + Otsu** | 118 | **가장 깨끗한 병뚜껑 형태** — 점이 줄고 경계가 매끄러움 |
| CLAHE(2.0) + Otsu | 132 | 윗면은 잘 분리되지만 아래 링에 점 Noise와 구멍이 생김 |

판단: 이 기준 이미지에서는 **Gaussian + Otsu**가 3일차 Contour 측정에 가장 유리하다.
CLAHE는 눈으로 보기에는 선명하지만 Binary에서는 오히려 조각이 늘었다.

## Challenge

### 문제

전체 밝기 평균 124로 극단적으로 어둡지는 않지만, **흰 병뚜껑과 회색 배경이 모두 밝은 계열**이다.
배경(위쪽 모서리 평균 134~147)이 병뚜껑 몸통(평균 131)보다 오히려 밝아서, 밝기만으로 병뚜껑과 배경을 나누기 어렵다.

### 시도한 전처리

Brightness, Gamma, CLAHE (`17_day02_challenge.py`의 TODO 부분)

### 비교한 Parameter

beta = 40 / gamma = 1.5, 2.0 / clipLimit = 1.0, 2.0, 3.0

### 최종 선택

**전처리 미사용** (원본 그대로 `challenge_result.jpg`)

### 선택 이유

| 시도 | Otsu 값 | 흰색 비율 | Binary 조각 수 | 배경 모서리 흰색 | 병뚜껑 몸통 흰색 |
|---|---:|---:|---:|---:|---:|
| 원본 | 111 | 82.5% | 584 | 100% | 100% |
| beta 40 | 151 | 82.5% | 584 | 100% | 100% |
| gamma 1.5 | 143 | 85.4% | 455 | 100% | 100% |
| gamma 2.0 | 163 | 87.6% | 295 | 100% | 100% |
| CLAHE 1.0 | 113 | 83.6% | 778 | 100% | 99% |
| CLAHE 2.0 | 125 | 63.4% | 2929 | 96~100% | 44% |
| CLAHE 3.0 | 130 | 53.3% | 3855 | 70~99% | 20% |

어떤 전처리도 **배경 모서리를 검은색으로 만들지 못했다**(병뚜껑-배경 분리 개선 없음).
CLAHE 3.0에서 배경이 조금 검어진 것보다 병뚜껑 몸통이 훨씬 더 검게(20%) 부서져, 오히려 병뚜껑이 배경보다 "덜 객체"가 되었다.
원인은 화질이 아니라 **촬영조건(밝은 배경)** 이므로 전처리를 추가하지 않는다.

### 좋아진 점

- Gamma는 Binary의 작은 조각 수를 줄였다(584 → 295).
- CLAHE는 병뚜껑의 세로 홈을 눈으로 보기 좋게 강조했다.

### 나빠진 점

- CLAHE 2.0 이상에서 병뚜껑 내부가 흑백 점으로 부서져 객체가 쪼개졌다.
- Gamma·Brightness는 배경도 함께 밝아져 분리가 좋아지지 않았다.

### Otsu 비교 결과

전처리 전·후 모두 병뚜껑과 배경이 함께 흰색으로 나온다.
반대로 **어두운 경계선(병뚜껑-링 사이 틈, 병 목)** 은 모든 조건에서 검은색으로 일정하게 분리된다.

## glare.jpg — 촬영환경 사례

- 한쪽에서 강한 조명 → 벽에 밝은 원형 영역과 위쪽 그림자가 생김
- 흰 병뚜껑이 밝은 영역 안에 있어 배경과 밝기가 비슷함
- 255 근처로 포화된 픽셀은 0% → 정보가 완전히 사라지지는 않았음

판단: 전처리를 더하기보다 **조명 방향 · 배경색(어두운 배경) · 카메라 각도**를 먼저 바꾼다.
