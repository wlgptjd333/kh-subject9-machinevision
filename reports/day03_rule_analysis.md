## 병뚜껑 Rule 실습 (18~22)

### Morphology (18) — Kernel 비교

| Kernel | Opening | Closing |
|---|---|---|
| 3×3 | 작은 흰 점이 지워짐, 뚜껑-링 사이 틈은 그대로 | 링 안쪽 작은 틈이 일부 메워짐 |
| 5×5 | 경계가 조금 둥글어짐 | 뚜껑-링 틈이 짧은 조각으로 줄어듦 |
| 9×9 | 모서리가 많이 둥글어짐 | **뚜껑과 링이 한 덩어리로 붙음** — 틈 정보가 사라짐 |

판단: 노이즈는 적고 뚜껑-링 경계는 남기는 **3×3**(Rule 코드가 쓰는 값). 9×9는 너무 강하다.

### Feature 비교 (20) — 기준 이미지 2장

| Feature | cap_on | cap_off | 판단 |
|---|---:|---:|---|
| otsu_value | 111 | 116 | 밝기 기준값일 뿐, 유무와 직접 관계없음 |
| valid_count | 3 | 1 | 차이는 있지만 노이즈·Morphology에 따라 흔들림 |
| largest_area | 27,878 | 19,347 | ROI 크기에 따라 바뀌는 절대값 |
| **largest_area_ratio** | **0.661** | **0.459** | ROI 크기와 무관하게 비교 가능 → **선택** |
| center_x_norm | 0.491 | 0.536 | 차이 작음 |
| center_y_norm | 0.461 | 0.551 | 보조 정보 |
| touches_border | False | True | ROI 설정에 따라 바뀜 → 보조 정보 |

### Rule (21)

- Threshold = (0.661 + 0.459) / 2 = **0.560**, 뚜껑이 있으면 비율이 더 크다 (`GREATER`)
- `area_ratio ≥ 0.560 → OK`, 미만 → `NG` (`NG_CAP_AREA`)
- 기준 이미지 2장 모두 맞게 판정 — 하지만 **Rule을 만든 이미지로 확인한 것이라 성능이 아니다** (19절)

### Batch Test (22) — 640×480 새 촬영 6장

기준: `cap_on_001` 0.438 / `cap_off_001` 0.284 → Threshold **0.361**, 나머지 4장으로 확인

| 이미지 | 정답 | 판정 | largest_area_ratio | Threshold와 차이 |
|---|---|---|---:|---:|
| cap_on_002 | cap_on | OK ✅ | 0.560 | +0.199 |
| cap_on_003 | cap_on | OK ✅ | 0.457 | +0.096 |
| cap_off_002 | cap_off | NG ✅ | 0.290 | −0.071 |
| cap_off_003 | cap_off | NG ✅ | 0.317 | **−0.044** |

- **4/4 일치**. 다만 `cap_off_003`은 기준과 0.044 차이로 여유가 작다.
- 같은 병뚜껑인데 **기준 세트에 따라 Threshold가 0.560 ↔ 0.361로 크게 다르다.**
  21의 0.560을 이 6장에 그대로 쓰면 `cap_on_003`(0.457)·`cap_on_002`(0.5599)가 NG가 된다.
  → 해상도·거리·ROI를 바꿔 다시 찍으면 기준값을 **다시 정해야** 한다 (20.1절 "해상도 통일"의 이유).
- `cap_off`는 병 입구 나사산 사이가 여러 조각으로 잡혀 `valid_count`가 6~7로 커진다 — 개수는 Rule로 쓰기 어렵다.

# Day 03 Mini Challenge 결과

## 1. 검사 문제

검사 대상: 갈색 유리병 입구의 빨간 왕관 뚜껑 (1일차 `sample.mp4` → `06_video_roi.py` ROI)

정상 상태: 빨간 왕관 뚜껑이 닫혀 있음 (`ok_01` = frame 90, `ok_02` = frame 60)

불량 상태: 뚜껑 없이 투명 유리 입구만 보임 (`ng_01` = frame 210, `ng_02` = frame 240)

> 직접 촬영 대신 1일차 영상 Frame을 사용했다. 1일차 Mini Challenge에서 세운 가설("빨간색 비율로 구분")을 확인하는 목적.

## 2. 사용한 처리

처리 흐름:

HSV
→ 빨간색 Mask (H 0~10 + 170~180, S ≥ 80, V ≥ 60)
→ Opening 3×3
→ Contour (ROI의 0.1% 미만 제외)
→ 가장 큰 빨간 덩어리의 면적 비율

병뚜껑 실습과 달리 **Gray·Otsu가 아니라 HSV**를 썼다 — 투명 유리·흰 배경 vs 빨간 뚜껑은 밝기보다 색이 차이를 만든다.

## 3. 선택한 Feature

Feature: `largest_area_ratio` (가장 큰 빨간 덩어리 면적 / ROI 면적)

선택 이유: 뚜껑이 있으면 넓은 빨간 덩어리가 하나 생기고, 없으면 유리에 비친 작은 붉은 점만 남는다. 비율이라 ROI 크기와 무관.

## 4. 실제 측정값

정상: ok_01 = 0.0935

불량: ng_01 = 0.0030

## 5. Rule

OK 조건: `largest_area_ratio ≥ 0.048` (두 측정값의 중간)

NG 조건: `largest_area_ratio < 0.048`

NG Reason: `NG_RED_CAP_AREA`

## 6. 새로운 이미지 확인

확인한 이미지 수: 2장 (ok_02, ng_02 — Rule 고정 후 적용)

올바른 판정: 2 (ok_02 = 0.0961 → OK, ng_02 = 0.0029 → NG)

틀린 판정: 없음

## 7. 결과 해석

잘 동작한 부분: 정상·불량 차이가 약 30배로 커서 기준값 주변에 여유가 많다.

문제가 있었던 부분: 뚜껑이 없는 이미지에도 유리 반사로 붉은 점(0.3%)이 잡힌다.

수정한 내용: 없음 — Opening과 "가장 큰 덩어리" 기준으로 이미 판정에 영향이 없었다.

## 8. 결론

가장 중요했던 Feature: 빨간색 면적 비율 (색 기반 Mask)

실패할 수 있는 조건:
- 뚜껑 색이 빨강이 아닌 제품 (Hue 범위를 다시 정해야 함)
- 손·병따개가 뚜껑을 가리는 Frame (1일차 frame 150 같은 경우)
- 조명이 바뀌어 채도(S)가 80 아래로 떨어질 때
- 배경에 빨간 물체가 ROI 안으로 들어올 때
