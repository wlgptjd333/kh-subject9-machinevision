# Part A. 강사 예제 — 페트병 병뚜껑

## ROI를 맞춘 기준

`03_roi_crop.py` 리뷰(STEP 18 격자)에서 `sample01`의 병뚜껑 네 변을 읽었습니다.

- 병뚜껑 위치: x ≈ 190 ~ 450, y ≈ 140 ~ 445
- 위·왼쪽·오른쪽은 20px 정도 여유, 아래는 병 목 고리(y ≈ 460~) 직전까지

## ROI 변경 기록

| 버전 | ROI (x1, y1, x2, y2) | 결과 |
|---|---|---|
| 교재 예시 | (200, 100, 700, 500) | x2가 이미지 너비 640을 넘어 640으로 보정됨. 오른쪽 배경이 많음 |
| 1차 | (170, 120, 470, 450) | `sample01`에 바짝 맞춤 → `sample02`에서 뚜껑 아래 링이 약 30px 잘림 |
| **최종** | **(170, 120, 470, 490)** | 아래쪽만 40px 여유 → 정상 3장 모두 뚜껑 전체가 들어옴 (`sample01`은 병 목이 조금 더 포함됨) |

`03_roi_crop.py`(한 장)는 1차 좌표, `04_batch_roi.py`(여러 장)는 최종 좌표를 사용합니다.

## 결과 기록 (최종 ROI 기준, 1차 ROI 관찰 포함)

| 이미지 | 실제 상태 | ROI 결과 | 관찰 |
|---|---|---|---|
| `sample01` | 뚜껑 있음 | 성공 | ROI를 처음 정한 기준 이미지. 뚜껑 x 190~450, y 140~445 |
| `sample02` | 뚜껑 있음 | 1차 부분 실패 → 최종 성공 | 병이 더 아래에 있고 뚜껑이 좁음(y 190~480). 1차 ROI(y2=450)에서는 아래 링이 잘림 |
| `sample03` | 뚜껑 있음 | 1차 경계 → 최종 성공 | 뚜껑 아래쪽(y ≈ 455)이 1차 ROI 경계에 걸림 |
| `sample04` | 뚜껑 없음 | ROI 정상 | ROI 위치는 맞고, 그 안에 나사산이 보이는 병 입구만 있음 → 제품 불량 |
| `sample05` | 뚜껑 없음 | ROI 정상 | 병 크기가 조금 작지만 병 입구 영역을 그대로 검사하고 있음 → 제품 불량 |

- 모든 이미지의 해상도는 640 × 640으로 같습니다.
- `sample02`·`sample03`의 문제는 **검사 영역(ROI) 설정 문제**, `sample04`·`sample05`는 **제품 상태의 차이(불량)**입니다.

```
한 장에서 잘 맞는 ROI ≠ 모든 이미지에서 잘 맞는 ROI
```

# Part B. Mini Challenge — 유리병 왕관 뚜껑

## 1. 검사 대상

검사할 제품: 갈색 유리병 입구의 왕관 뚜껑(빨간색 금속 크라운 캡)

## 2. 정상 조건

정상 상태: 병 입구에 빨간 왕관 뚜껑이 닫혀 있음 (`frame_00060` ~ `frame_00120`)

## 3. 불량 조건

불량 상태: 병 입구에 뚜껑이 없고 투명한 유리 입구가 그대로 보임 (`frame_00180` ~ `frame_00240`)

## 4. 검사 ROI

```
x1 = 430
y1 = 90
x2 = 760
y2 = 260
```

(영상 크기 1280 × 720, `src/03_roi_crop_challenge.py` · `src/04_batch_roi_challenge.py`)

## 5. 왜 이 영역을 ROI로 선택했는가?

뚜껑 유무만 판단하면 되므로 병 몸통·손·배경은 볼 필요가 없습니다. 뚜껑이 있어야 하는 **병 입구 주변만** 선택했습니다.

- v1 (500, 110, 740, 230): `frame_00090`의 뚜껑(x 535~720, y 130~175)에 맞춤
- v2 (430, 90, 760, 260): `frame_00060`에서 병이 왼쪽에 있어 뚜껑(x 460~640) 왼쪽이 잘림 → 왼쪽 70px, 위아래 20~30px 여유 추가

비교 이미지: `outputs/challenge_roi/compare_v1_rois.png`, `compare_v2_rois.png`

## 6. 여러 이미지에 같은 ROI를 적용한 결과 (v2)

| 이미지 | 결과 | 관찰 |
|---|---|---|
| frame_00030 | 실패 | 병이 화면으로 들어오는 중이라 ROI에 병 어깨만 보임 (검사 대상 위치 자체가 다름) |
| frame_00060 | 성공 | 뚜껑 있음. v1에서는 왼쪽이 잘렸고 v2에서 해결 |
| frame_00090 | 성공 | 뚜껑 있음 (기준 Frame) |
| frame_00120 | 성공 | 뚜껑 있음. 오른쪽 위에 손가락이 조금 들어옴 |
| frame_00150 | 부분 성공 | 뚜껑은 있지만 병따개와 손이 ROI를 가림 |
| frame_00180 | 성공 | 뚜껑 없음(열린 직후). 날아가는 뚜껑이 ROI 왼쪽 가장자리에 걸림 |
| frame_00210 | 성공 | 뚜껑 없음 |
| frame_00240 | 성공 | 뚜껑 없음 |

## 7. ROI 판단

- **ROI 범위를 조금 넓혀야 함** (v1 → v2로 해결)
- 단, 병이 들어오는 중인 구간(`frame_00030`)과 손·도구가 가리는 구간(`frame_00150`)은 고정 ROI만으로는 판단하기 어려움
  → 실제 검사라면 병이 멈춘 Frame만 검사하거나, 이후 수업의 위치 찾기(Template Matching 등)가 필요

## 8. 눈으로 보이는 정상·불량의 차이

- 정상: ROI 위쪽에 **빨간색**의 톱니 모양 금속 뚜껑이 넓게 보임
- 불량: 빨간색이 사라지고 **투명한 유리 입구**와 흰 배경만 보임

## 9. 컴퓨터가 나중에 측정할 수 있을 것 같은 값

- 색상: ROI 안의 **빨간색 픽셀 비율** (HSV)
- 면적: 뚜껑 영역(빨간색)의 면적
- 이미지 유사도: 정상 기준 ROI(`frame_00090_roi.jpg`)와의 차이

## 10. 현재 검사 가설

병 입구 ROI에서 빨간색 픽셀 비율을 측정하면 뚜껑이 있는 상태(빨간색 많음)와 없는 상태(거의 없음)를 구분할 수 있을 것이다.

## 11. 아직 모르는 것

- 빨간색으로 판단할 정확한 색 범위와 기준 비율은 아직 모른다.
- 손(피부색)이나 병따개가 ROI를 가릴 때 오판하지 않는 방법은 아직 모른다.
- 병이 움직이는 Frame을 검사에서 어떻게 제외할지 아직 모른다.

이후 수업(2일차 Image Enhancement 등)에서 직접 확인한다.
